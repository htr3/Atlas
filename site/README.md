# System Design Atlas

An interactive 2D study companion with separate visual courses:

- **System Design** — the original 26 lectures in `data/system-design/`
- **New Concepts** — lectures that were not already covered, in `data/concepts/`, including the later service-pattern and Kafka lessons
- **Low-Level Design** — all 10 available LLD lessons in `data/lld/`
- **Design Marvel** — 11 distributed-systems paper walkthroughs in `data/marvel/`
- **Interview Prep** — 13 interview and algorithm lessons in `data/interview/`
- **Competitive Programming** — 12 non-duplicate advanced lessons in `data/competitive/`
- **Abdul Bari Algorithms** — 77 available lessons from the 84-entry playlist in `data/abdul-bari/`
- **Piyush Garg** — 15 separate system design lessons (event sourcing, CQRS, rate limiting, UPI, WebRTC, queues, patterns, Kafka) in `data/piyush-garg/`
- **SD Roadmap** — 40 Java/Spring-oriented lessons covering the missing networking, data, reliability, security, cloud, operations, advanced, and case-study topics in `data/sd-roadmap/`
- **Striver Sheet** — 229 Java DSA problems across 17 modules, generated from `raw data/Striver-180-Java-Notes.pdf`

```powershell
cd "C:\Users\admin\All\gaurav sen\site"
py -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Controls

- Drag to pan the architecture diagram
- Scroll to zoom
- Double-click to reset the diagram
- Left / right arrow keys change visualization steps
- Space plays or pauses the walkthrough
- `/` focuses lecture search
- Use **Theory** to jump to notes, terminology, trade-offs, and interview tips
- Completed lectures are saved in this browser

The complete lecture content and diagram renderer run locally; only the optional Google font needs the internet.
